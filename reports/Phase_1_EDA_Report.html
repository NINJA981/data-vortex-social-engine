1.1 Deduplication

  • Observation: 360 rows in the posts file are exact, byte-for-byte duplicates.
  • Root cause: a retry loop in the upstream gateway replayed timed-out ingestion requests.
  • Action: exact-row deduplication, dropping all 360 rows.
  • Verification: 12,000 unique records remain, exactly 8.0 posts per user (12,000 / 1,500), with zero orphaned posts against the user table.

1.2 Multi-Format Timestamp Normalization

A single pd.to_datetime() call fails because the stream merged three clock sources:

  • Unix epoch seconds — e.g. 1722528840, 1719394663
  • Day-first European dates — e.g. 25-09-2024, 10-09-2024
  • ISO-8601 timestamps — e.g. 2025-04-13T20:12:18

A regex-dispatched parser in scripts/clean_social_engine.py handles each case:

def parse_timestamp(value):
    if value.isdigit():
        return pd.to_datetime(int(value), unit="s")
    if re.match(r"^\d{2}-\d{2}-\d{4}", value):
        return pd.to_datetime(value, dayfirst=True)
    return pd.to_datetime(value)

Verification: all 12,000 timestamps parsed with zero NaT errors and were normalized to UTC (YYYY-MM-DD HH:MM:SS). The timeline spans 2024-01-05 01:35:53 to 2025-12-04 20:36:17.

1.3 Negative Likes: Sign-Inversion Proof

  • Observation: 509 posts carry negative likes (minimum -4,987, maximum -11, mean -2,460.7).
  • Hypothesis: the negative sign is an integer sign-bit flip introduced during stream serialization, not a legitimate penalty score.
  • Test: a two-sample Kolmogorov–Smirnov test comparing the absolute values of the negative likes (n = 509) against the positive likes (n = 9,676) gives D = 0.0312, p = 0.7042. Since p > 0.05, the two distributions are statistically indistinguishable, so replacing likes with abs(likes) restores the original values without distorting the variance.

Audit tracking: all 509 corrected records carry the flag is_likes_sign_corrected = 1.

1.4 Missing Likes: Platform-Stratified Median Imputation

1,814 posts (about 15% of the dataset) have missing likes. Dropping them would discard valid shares, comments, text, and user joins; global mean imputation would artificially compress the variance. The pipeline instead applies a per-platform median:

Platform Median likes (imputed value)
Facebook 2,529
Instagram 2,501
Reddit 2,488
Twitter 2,438
YouTube 2,518

Audit tracking: imputed records carry the flag is_likes_imputed = 1, so any downstream analyst can filter or isolate them.

1.5 Text Sanitization and Pseudo-Null Removal

72 rows contain pseudo-null string artifacts instead of real text. The most frequent variants:

Artifact Rows
'NULL\n\n' 23
'NULL&' 20
'NULLé' 19
'NULL<div>' 17
'NULL<br>' 12

Fix: every variant matching ^NULL(\s*|&|é|<div>|<br>|\n*)$ is mapped to a standard null value. Additionally, HTML entities are decoded (&amp; to &) and residual tags are stripped from the 974 records affected by entity corruption.

1.6 Missing Platform: Model-Based Imputation

1,784 posts lack a platform value. A Random Forest classifier (100 trees) is trained on the 10,216 labeled posts using TF-IDF text features (300 n-grams) plus engagement metrics (likes_clean, shares, comments). Rows with usable text are assigned the predicted platform; the remainder are labeled 'Unknown'.

Audit tracking: imputed records carry the flag is_platform_imputed = 1.
